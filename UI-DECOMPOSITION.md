## Decomposition contract

Each generated native page carries one semantic composition. Regions have a stable identity, purpose, priority, reading order, responsibility and typed binding. The hierarchy has one root and explicit containment. Native realization names the component and existing DOM node for each supported region. The retained lowerer emits binding annotations and a hash-bound receipt; the retained verifier reconstructs that lowering before accepting it.

Native image leaves and other representation primitives are accounted for by component adoption. Imported article internals and dynamically generated collection controls have explicit runtime-adoption boundaries. Composition coverage is not inflated by pretending those internals were individually lowered by the semantic region compiler.

## Interaction contract

The presentation source owns every collection title, query label, filter path, comparison operator, page size, count label and action binding. The retained receiver supplies only its existing generic predicates, paging and rendering. Removing a declaration removes its corresponding surface; no default scientific categories are inferred by client code.

The only publication action is navigation to a declared local record. It cannot execute a Sourcery operation, change a research claim or mutate a backend. Normal links preserve access to the corpus when JavaScript is unavailable.

The browser adopts native controls through the existing component catalogue. Labels, keyboard focus, empty states, paging and narrow layouts are part of qualification. The native implementation and CSS provider remain trusted boundaries, not mathematical proof of browser behavior.

## Algebra and scientific scope

All decomposed corpus records carry the twelve-coordinate kernel. Joint-input bridges retain all input identities. Representation changes, physical symmetry reductions, information losses, open-system passages and evidential selection remain differently typed.

The executable common-algebra demonstration composes dimensionless records about publication. Its dimensions do not stand for the energies, rates or ages described inside those records. The deliberate attempted promotion to a confirmed ancient process is rejected.

The additional worked-quantity receipt separately instantiates actual SI exponent signatures for a conditional silica-to-carbonate mass map and a molar-flux-to-recession-speed map. It declares the dimensionless stoichiometric coefficient and the molar-volume coefficient with dimension m³/mol. The retained composer verifies dimension deltas and signature changes; the numerical adapter evaluates the arithmetic. Neither check verifies the mechanism's applicability or supplies a measured surface flux. A corrupted molar-volume dimension is rejected in qualification.

The generated `data/publication-receipt.json`, `data/semantic-decomposition.json`, `data/record-composition.json` and per-route `data/ui/` files supply the inspectable result. They are reading and qualification projections; the research and presentation sources retain authority.
