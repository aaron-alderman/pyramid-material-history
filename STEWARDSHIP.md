# Repository stewardship

This is a source repository for **The Missing Middle: Pyramid Material History**. Canonical remote: [`aaron-alderman/pyramid-material-history`](https://github.com/aaron-alderman/pyramid-material-history).

The [licensing notice](LICENSE.md) states the software and content grants. The [Christian Stewardship Covenant](CHRISTIAN_STEWARDSHIP_COVENANT.md) asks for truthful witness, humility, attribution and service; it is voluntary and adds no legal restriction. Existing file-specific and third-party notices control their own material.

## Keep the repository small and truthful

- Edit the declared source owners and regenerate outputs through the supported build. Source, supplied bootstrap definitions, generated output and historical evidence have different roles.
- Keep local dependencies, editor/OS state, private environment files and temporary build work out of commits. Ignore rules do not authorize deleting files.
- Keep tracked deployment output where the publication contract requires it. Do not delete a retained dist tree merely because it looks generated.
- Preserve correction history, attribution, failed tests, source oracles, retained predecessors and hash-bound receipts. Evidence logs are not disposable application logs.
- Before removing a scratch directory, identify its owner, verify its resolved path, check that no source or unique evidence depends on it and retain a bounded receipt. Do not follow junctions, prune Git objects, rewrite history or reset someone else's working changes during routine hygiene.
- Archive or retire an older checkout explicitly when a successor is verified; its name or age alone does not establish that it is redundant.

A clean working tree is not proof of architectural completeness, scientific truth, production readiness or independent review.
